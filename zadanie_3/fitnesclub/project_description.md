# Описание проекта: Фитнес-клуб

## Идея

Веб-приложение для управления тренировками и записи к тренеру в фитнес-клубе.

## Проблема

Люди, которые ходят в фитнес-клуб, сталкиваются с несколькими сложностями:
- Не знают актуальное расписание тренировок
- Не могут быстро записаться к нужному тренеру
- Не видят свою историю посещений и прогресс
- Не понимают, какая программа тренировок подходит под их цель

Единого места, где всё это собрано, нет — приходится звонить, писать в мессенджеры или искать информацию на разных сайтах.

## Целевая аудитория

**Основная аудитория:**
- Люди 18–45 лет
- Ходят в фитнес-клуб или только собираются начать
- Хотят удобно планировать тренировки и отслеживать прогресс

**Сегменты:**
1. Новички — не знают, с чего начать, нуждаются в подсказках и записи к тренеру
2. Опытные — хотят быстро записываться на групповые занятия и видеть статистику
3. Занятые — ценят время, хотят записаться за 2 клика

## Ключевые функции (MVP)

### 1. Просмотр расписания тренировок
Пользователь видит список предстоящих тренировок: дата, время, тип (йога, силовая, кардио), тренер, свободные места.

### 2. Запись на тренировку
Пользователь выбирает тренировку из расписания и записывается в 2–3 клика. Может отменить запись.

### 3. Личный кабинет с историей тренировок
Пользователь видит свои записи: предстоящие и прошедшие. Видит, сколько тренировок посетил, какие типы предпочитает.

### 4. (Бонус) Программы тренировок по целям
Пользователь выбирает цель (похудение, набор массы, поддержка формы) — получает рекомендованную программу.

## Ценность проекта

- **Для пользователя:** экономит время, всё в одном месте, помогает не бросить тренировки
- **Для клуба:** повышает удержание клиентов, снижает нагрузку на администраторов
