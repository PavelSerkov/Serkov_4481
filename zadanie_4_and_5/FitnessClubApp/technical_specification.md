# Техническое задание: Фитнес-клуб

## 1. Описание проекта

Веб-приложение для фитнес-клуба, которое позволяет пользователям:
- просматривать расписание тренировок;
- записываться на тренировки онлайн;
- отслеживать историю посещений в личном кабинете.

**Цель:** упростить запись на тренировки и повысить удержание клиентов клуба.

**Технологический стек (предполагаемый):**
- Frontend: HTML5, CSS3, JavaScript (или React)
- Backend: Node.js + Express (или Python + FastAPI)
- База данных: PostgreSQL
- Аутентификация: JWT

## 2. Целевая аудитория

- Люди 18–45 лет, ходят в фитнес-клуб или только собираются начать
- Сегменты: новички, опытные, занятые
- Платформа: веб (десктоп + мобильные)

## 3. Функциональные требования

### 3.1. Просмотр расписания тренировок

- Отображать список тренировок на 7 дней вперёд
- Для каждой тренировки: дата, время, тип (йога, силовая, кардио), тренер, место, свободные места
- Поддерживать фильтрацию по типу тренировки
- При отсутствии тренировок показывать сообщение «Пока нет доступных тренировок»

### 3.2. Запись на тренировку

- Пользователь может записаться на тренировку в 2 клика
- Если пользователь не авторизован — открывается форма входа
- Если мест нет — кнопка «Записаться» неактивна, показано «Мест нет»
- После записи показывается подтверждение

### 3.3. Личный кабинет

- Показывать список предстоящих тренировок
- Показывать список прошедших тренировок
- Возможность отменить запись (не позднее чем за 2 часа до начала)
- При отсутствии записей — сообщение «У вас пока нет записей»

### 3.4. Программы тренировок по целям (Nice to have)

- Пользователь выбирает цель: похудение, набор массы, поддержка формы
- Показывается список рекомендованных тренировок (3–5 штук)
- Цель сохраняется в профиле

## 4. Нефункциональные требования

- **Производительность:** страница расписания загружается быстрее 2 секунд
- **Адаптивность:** корректная работа на мобильных (от 360px) и десктопе (до 1920px)
- **Браузеры:** Chrome, Firefox, Safari, Edge (последние 2 версии)
- **Доступность:** контрастность не ниже AA, поддержка клавиатурной навигации
- **Безопасность:** пароли хранятся в хешированном виде (bcrypt), HTTPS обязателен, JWT-токены с ограниченным сроком жизни

## 5. Обработка ошибок и негативные сценарии

### 5.1. Ошибки валидации

- **Пустая форма входа** → подсветка полей, сообщение «Заполните все поля»
- **Неверный email** → «Введите корректный email»
- **Слабый пароль** (меньше 8 символов) → «Пароль должен быть не менее 8 символов»

### 5.2. Отсутствие данных

- **Нет тренировок на неделю** → «Пока нет доступных тренировок. Загляните позже»
- **Нет записей у пользователя** → «У вас пока нет записей. Запишитесь на тренировку»
- **Нет программ под цель** → «Программы для этой цели скоро появятся»

### 5.3. Сетевые ошибки

- **Потеря соединения при загрузке** → «Не удалось загрузить данные. Проверьте интернет и попробуйте снова»
- **Ошибка при записи на тренировку** → «Не удалось записаться. Попробуйте позже»
- **Таймаут сервера** → «Сервер не отвечает. Повторите попытку через минуту»

### 5.4. Неавторизованный доступ

- **Попытка записаться без входа** → редирект на форму входа, после успешного входа — возврат к тренировке
- **Попытка открыть личный кабинет без входа** → редирект на форму входа
- **Истёк JWT-токен** → автоматический выход и сообщение «Сессия истекла. Войдите снова»

### 5.5. Бизнес-ограничения

- **Отмена записи менее чем за 2 часа** → «Отмена невозможна менее чем за 2 часа до начала»
- **Повторная запись на ту же тренировку** → «Вы уже записаны на эту тренировку»
- **Превышен лимит записей (например, 5 активных)** → «Достигнут лимит активных записей»

## 6. UX-решения для обработки ошибок

- Все сообщения об ошибках — на русском языке, понятным текстом
- Ошибки валидации — подсветка поля + текст под ним
- Системные ошибки — всплывающее уведомление сверху страницы (toast)
- Критические ошибки (потеря соединения) — модальное окно с кнопкой «Повторить»
- Пользователь всегда видит, что делать дальше (кнопка действия)

## 7. Ограничения и предположения

- Аутентификация — по email и паролю
- Оплата тренировок не входит в MVP
- Мобильное приложение не входит в MVP (только веб)
- Интеграция с календарём (Google Calendar) — отложена на следующую итерацию
