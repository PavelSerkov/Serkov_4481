# Шаг 3. Библиотека промпт-шаблонов (RTCF)

> Каждый шаблон построен по структуре RTCF:
> **R**ole — кем является AI
> **T**ask — что нужно сделать
> **C**ontext — что AI должен знать
> **F**ormat — в каком виде вернуть результат

---

## Шаблон 1. Генерация компонента/функции по описанию

**Role:** Ты — Senior Frontend Developer, пишешь чистый JavaScript без фреймворков.
**Task:** Создай функцию {имя_функции}, которая {что делает}.
**Context:** Проект — калькулятор на HTML5 + CSS3 + JavaScript, всё в одном файле index.html. Без библиотек. Стиль: camelCase, 2 пробела, комментарии на русском.
**Format:** Код в одном блоке с комментариями. После кода — 2–3 строки пояснения, что делает функция.

**Пример использования:**
> **Role:** Ты Senior Frontend Developer.
> **Task:** Создай функцию calculateResult, которая принимает два числа и оператор, возвращает результат.
> **Context:** Калькулятор на чистом JS, обработка деления на ноль обязательна.
> **Format:** Код + пояснение.

---

## Шаблон 2. Рефакторинг кода с улучшением

**Role:** Ты — опытный разработчик, специалист по рефакторингу.
**Task:** Отрефактори следующий код: {код}. Улучши читаемость, убери дублирование, исправь стиль.
**Context:** Проект — калькулятор на чистом JS. Правила: camelCase, const/let, без eval(), комментарии на русском.
**Format:** Сначала — список изменений (что и почему), затем — новый код.

**Пример использования:**
> **Task:** Отрефактори эту функцию обработки кликов: (вставить код).
> **Context:** Сейчас используется var и повторяющиеся блоки.
> **Format:** Список изменений + новый код.

---

## Шаблон 3. Написание тестов для существующего кода

**Role:** Ты — QA-инженер, пишешь тесты на JavaScript.
**Task:** Напиши тесты для функции {имя_функции}.
**Context:** Функция находится в index.html, чистый JS, без тестовых фреймворков. Нужно проверить: {сценарии}.
**Format:** Простой самодельный тест-скрипт (без Jest/Mocha) с выводом результатов в консоль.

**Пример использования:**
> **Task:** Напиши тесты для calculateResult.
> **Context:** Проверить: сложение, вычитание, умножение, деление, деление на ноль.
> **Format:** Скрипт с assert-подобными проверками.

---

## Шаблон 4. Исправление ошибок и багов

**Role:** Ты — разработчик, специалист по отладке.
**Task:** Найди и исправь ошибку в коде: {описание проблемы}.
**Context:** Проект — калькулятор на чистом JS. Вот код: {код}. Вот что происходит: {поведение}.
**Format:** 1) Причина ошибки. 2) Исправленный код. 3) Как проверить, что баг исчез.

**Пример использования:**
> **Task:** Кнопка "=" не реагирует на клик.
> **Context:** Код обработчика: (вставить). Событие не срабатывает.
> **Format:** Причина + исправление + проверка.

---

## Шаблон 5. Декомпозиция сложной задачи на подзадачи

**Role:** Ты — техлид, умеешь декомпозировать задачи.
**Task:** Разбей задачу «{большая задача}» на подзадачи.
**Context:** Проект — калькулятор на чистом JS. Задача должна быть выполнена за несколько итераций.
**Format:** Нумерованный список подзадач. Для каждой — 1 строка описания и ожидаемый результат.

**Пример использования:**
> **Task:** Разбей задачу «Добавить в калькулятор историю вычислений» на подзадачи.
> **Context:** Без фреймворков, всё в index.html.
> **Format:** 3–4 подзадачи с ожидаемым результатом.
