# Шаг 1. Описание проекта и стека

## Проект
Веб-приложение «Калькулятор» с базовыми арифметическими операциями.

## Технологический стек
- HTML5
- CSS3
- JavaScript (ES6+)
- Без фреймворков, без сторонних библиотек, без сборщиков

## Архитектура
- Один файл `index.html`
- Внутри: `<style>` в `<head>`, разметка в `<body>`, `<script>` в конце `<body>`
- Логика: обработчики кликов на кнопках, хранение текущего значения и оператора в переменных

## Требования к стилю кода
- Имена переменных и функций — camelCase
- Имена CSS-классов — kebab-case
- Отступ — 2 пробела
- Комментарии на русском языке (для сложной логики)
- Точка с запятой в конце инструкций JS

## Ключевые ограничения
- Запрещено использовать `eval()` и `new Function()`
- Запрещено подключать внешние библиотеки и CDN
- Запрещено оставлять `console.log()` в финальном коде
